# 🛒 Grocery Store Web Application

A web-based Grocery Store e-commerce application built with **Python (Flask)**, **HTML5/CSS3**, and **SQLite**.

## ✨ Features
- Product catalog with images, pricing, and stock tracking
- User registration, login, and customer dashboard
- Admin management panel (`admin.html`)
- About, Services, and Contact pages

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3
- **Database:** SQLite (`users.db`)
